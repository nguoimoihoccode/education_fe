# Learning Coach Light Premium Redesign

## Direction

Use **Light Premium Coach** for `/learning-coach`.

## Goal

Make the dashboard look premium, calm, and focused. The learner should see one clear action, today's path, and weak areas without card clutter.

## Visual Design

- Soft light background with emerald and amber gradients.
- Clean white panels with subtle borders and shadows.
- Hero split into action summary and compact progress panel.
- Timeline-style daily path instead of dense card grid.
- Right column for coach insight and weak areas.

## UX

- One primary CTA above the fold.
- Metrics stay compact and secondary.
- Clickable items must have focus rings and hover states.
- Loading and error states remain styled.

## Scope

- Modify `src/pages/LearningCoach.tsx` only.
- Keep existing API and types.
- No backend changes.

## Verification

- Run frontend route/search tests.
- Run frontend build.
