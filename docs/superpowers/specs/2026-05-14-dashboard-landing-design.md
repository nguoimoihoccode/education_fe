# Dashboard Landing Design

## Goal

Create a dedicated `/dashboard-landing` page that looks like a premium education dashboard preview, separate from marketing landing `/`.

## Design

- Light premium dashboard style.
- Hero with dashboard title, value proposition, and CTA to `/education`.
- Quick action cards for Coach, Today, Quiz, Flashcards.
- Progress preview with streak and daily goal.
- Learning path timeline.
- Right sidebar with next action and weak areas.

## Scope

- Create `src/pages/DashboardLanding.tsx`.
- Update `/dashboard-landing` route to use the new page.
- Leave `/` landing unchanged.

## Verification

- Run route tests.
- Run frontend build.
